# Northstar Journal

Northstar Journal is a production-ready publishing platform built with Next.js, TypeScript, TailwindCSS, Prisma, PostgreSQL, Redis, and a clean feature-based architecture.

## Features
- Beautiful landing and home experiences
- Post discovery, category pages, tag pages, and search APIs
- Auth, dashboard, admin, and settings routes
- Database schema, Docker composition, CI workflow, documentation, and SEO support

## Quick Start
1. Copy `.env.example` to `.env.local` and fill in the required variables.
2. Install dependencies with `npm install`.
3. Run database migrations with `npx prisma migrate dev --name init`.
4. Start the local app with `npm run dev`.

## Deployment
Use Docker Compose, Vercel, Railway, DigitalOcean, or AWS with the included configuration files.
